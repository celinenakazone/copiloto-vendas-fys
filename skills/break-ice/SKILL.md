# Skill: Quebrar Gelo com FYS
Esta skill ensina a IA a transformar um problema de vendas em um roteiro prático.
## 📋 Instruções de Execução
1. **Identificar o Estabelecimento:** (Ex: bar, lanchonete, mercadinho de bairro).
2. **Identificar a Objeção:** (Ex: "A FYS é desconhecida", "Já vendo a Coca e está bom").
3. **Consultar a Base:** Verificar no arquivo `brand-fys.md` qual argumento se encaixa melhor (Heineken, preço, menos açúcar).
4. **Gerar duas saídas:**
   - **🗣️ Abordagem Presencial:** Um roteiro curto de 2 a 3 frases para o vendedor falar pessoalmente.
   - **📱 Mensagem de WhatsApp:** Um texto curto para enviar no celular do cliente.
